# n8n Webhook Forwarder
Sends a Telegram event to the automated n8n webhook queue.

## HOW TO USE
Invoke the local trigger script when the user sends an applicable command or presses a button generated by n8n.

### Text Message Workflow
Execute this exactly when the user sends a command (e.g. `/trends`):
`python3 /data/.openclaw/workspace/skills/n8n-webhook-trigger/scripts/trigger_n8n.py '{"chatId":"<CHAT_ID>","userId":"<USER_ID>","messageId":"<MSG_ID>","text":"<TEXT_INCLUDING_SLASH>","requestId":"<REQ_ID>"}'`

### Button Callback Workflow
Execute this exactly when the user presses an inline button (callback query):
`python3 /data/.openclaw/workspace/skills/n8n-webhook-trigger/scripts/trigger_n8n.py '{"chatId":"<CHAT_ID>","userId":"<USER_ID>","messageId":"<MSG_ID>","callbackData":"<CALLBACK_DATA>","sourceMessageId":"<SRC_MSG_ID>","sourceMessageText":"<SRC_TEXT>","requestId":"<REQ_ID>"}'`

## STRICT PASSTHROUGH COMMANDS (Codex patch)
Use this skill for ALL of these commands, not only `/trends`: `/carousel`, `/video`, `/video_talking`, `/video_kling`, `/meeting`, `/meeting_reels`, `/reels`, `/approve`, `/regenerate`, `/status`, `/help`.
After invoking this skill, do not post additional local assistant messages to the user; n8n will reply.
For callback buttons, always forward the exact `callbackData` value unchanged.
If `chatId` is prefixed (for example `telegram:8413229015`), strip the `telegram:` prefix before sending to n8n when possible.
